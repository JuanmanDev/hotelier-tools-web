MCP server คือตัวเชื่อมต่อที่ทำให้ผู้ช่วย AI อย่าง Claude หรือ ChatGPT ค้นข้อมูลและทำงานในซอฟต์แวร์อื่นได้ โดยใช้มาตรฐานเปิดที่เรียกว่า **Model Context Protocol** สำหรับโรงแรม หมายความว่าคุณถามได้ว่า "พรุ่งนี้ใครมาถึงและมียอดค้างชำระบ้าง?" แล้วผู้ช่วยจะดึงคำตอบจากระบบจัดการโรงแรม (PMS) ให้เอง โดยคุณไม่ต้องคัดลอกข้อมูลออกมา ณ เดือนตุลาคม 2026 มี PMS เพียงไม่กี่รายที่มี MCP อย่างเป็นทางการ Little Hotelier ยังไม่มี แต่คุณเชื่อมต่อผ่าน Hotelier Tools ได้

บทความนี้เป็นศูนย์รวมคู่มือ AI ของเรา แต่ละหัวข้อมีลิงก์ไปยังคู่มือทีละขั้นตอนเมื่อคุณพร้อมลงมือ

## MCP คืออะไร ย่อมาจากอะไร และใครเป็นคนสร้าง

MCP ย่อมาจาก **Model Context Protocol** Anthropic บริษัทเบื้องหลัง Claude [เปิดตัวเป็นมาตรฐานเปิด](https://www.anthropic.com/news/model-context-protocol)เมื่อวันที่ 25 พฤศจิกายน 2024 และในเดือนธันวาคม 2025 Anthropic [มอบให้ Agentic AI Foundation](https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation) ซึ่งเป็นกองทุนภายใต้ Linux Foundation ที่ Anthropic, Block และ OpenAI ร่วมกันก่อตั้ง ถึงตอนนั้น ChatGPT, Cursor, Gemini, Microsoft Copilot, Visual Studio Code และอีกหลายแอปก็รองรับ MCP แล้ว

MCP มีสองฝั่ง

- **MCP client** อยู่ในแอป AI ของคุณ: Claude, ChatGPT, Copilot
- **MCP server** อยู่ฝั่งซอฟต์แวร์ มีรายการ**เครื่องมือ (tools)** แต่ละอันมีชื่อและคำอธิบาย เช่น "get reservations by date range" หรือ "record a payment"

เมื่อคุณถาม AI จะอ่านรายการเครื่องมือ เลือกตัวที่เหมาะ เรียกใช้ แล้วตอบจากผลลัพธ์ที่ได้ คุณไม่ต้องเขียนโค้ดเลย

## MCP ต่างจาก API และแชตบอตอย่างไร: เทียบกับงานในโรงแรม

ลองนึกภาพว่า PMS คือออฟฟิศหลังบ้านที่เก็บสมุดการจองไว้

- **API** คือช่องหน้าต่างหลังบ้านที่มีแบบฟอร์มสั่งงานตายตัว ซอฟต์แวร์ใช้ช่องนี้ได้ แต่โปรแกรมเมอร์ต้องเขียนโค้ดสำหรับทุกแบบฟอร์มที่จะกรอก
- **MCP server** คือคอนเซียร์จที่ยืนอยู่ตรงช่องนั้น ยื่นเมนูบอกผู้ช่วย AI ทุกตัวว่าทำอะไรได้บ้าง ("ดูแขกที่จะมาถึง" "ตรวจยอดค้างชำระ" "เสนอการแก้ไข") กรอกแบบฟอร์มแทน และปฏิเสธสิ่งที่ไม่ได้รับอนุญาต MCP server ส่วนใหญ่สร้างอยู่บน API
- **แชตบอต** คือพนักงานต้อนรับที่อ่านแค่โบรชัวร์ คุยได้สุภาพ แต่เปิดสมุดการจองไม่ได้ ถ้าเชื่อมต่อ MCP ให้ ก็จะตรวจการจองจริงได้

| | คืออะไร | ใครใช้ | ตัวอย่างในโรงแรม |
|---|---|---|---|
| API | คำขอตายตัวสำหรับซอฟต์แวร์ | นักพัฒนา | "การจองที่เช็คอิน 1–30 เมษายน" |
| MCP server | เมนูเครื่องมือที่ AI ค้นพบและเรียกใช้ได้ | ผู้ช่วย AI | "พรุ่งนี้ใครมาถึงและมียอดค้างชำระ?" |
| แชตบอต | AI ที่พูดคุย | แขกหรือพนักงาน | "อาหารเช้ากี่โมง?" |

ถ้าอยากรู้เรื่องฝั่ง API อ่าน [Little Hotelier มี API ไหม?](/blog/little-hotelier-api)

## PMS โรงแรมตัวไหนมี MCP server บ้าง (ณ ตุลาคม 2026)

เราตรวจเว็บไซต์และเอกสารของแต่ละผู้ให้บริการเองเมื่อวันที่ 3 ตุลาคม 2026 "ไม่พบ" หมายถึงเราไม่พบเซิร์ฟเวอร์หรือประกาศอย่างเป็นทางการ ไม่ได้แปลว่าจะไม่มีในอนาคต

| PMS | มี MCP ทางการสำหรับข้อมูลของคุณเองหรือไม่ | เปลี่ยนข้อมูลได้ไหม | หมายเหตุ |
|---|---|---|---|
| Apaleo | มี (open beta) | อ่านและเขียน | ประมาณ 230 เครื่องมือ [เอกสารนักพัฒนา Apaleo](https://apaleo.dev/guides/ai/overview.html) ประกาศครั้งแรกเมื่อ[กันยายน 2025](https://apaleo.com/blog/apaleo-news/apaleo-launches-mcp-server) |
| Hospitable (บ้านเช่าตากอากาศ) | มี ตั้งแต่เมษายน 2026 | อ่านและเขียน | ระบุว่าข้อความที่ส่งผ่าน MCP "ส่งถึงแขกทันที" ไม่มีในแพ็กเกจ Essentials ([help](https://help.hospitable.com/en/articles/14424057-connect-an-ai-agent-to-hospitable-using-mcp)) |
| Guesty (บ้านเช่าตากอากาศ) | มี (early beta) | อ่านอย่างเดียว | ระบุว่า "experimental" ([docs](https://open-api-docs.guesty.com/docs/guesty-mcp-server-beta)) |
| Lodgify (บ้านเช่าตากอากาศ) | ประกาศแล้ว | อ่านและเขียน ตามที่ Lodgify ระบุ | [หน้า AI](https://www.lodgify.com/ai/)นำเสนอ "Lodgify MCP" เรายืนยันไม่ได้ว่าเปิดให้ใช้ทั่วไปแล้ว |
| Cloudbeds | เอกสารเท่านั้น | ไม่ | MCP ของ Cloudbeds ให้บริการ[เอกสารนักพัฒนา](https://developers.cloudbeds.com/docs/build-with-llms) ไม่ใช่ข้อมูลโรงแรม |
| Mews | ไม่พบ | — | มีเฉพาะโปรเจกต์ชุมชนที่ไม่เป็นทางการ เช่น[ตัวนี้บน GitHub](https://github.com/tjg37/mews-mcp-server) |
| Oracle OPERA Cloud | ไม่พบ | — | มีโปรเจกต์ชุมชนที่ไม่เป็นทางการ ([ตัวอย่าง](https://github.com/lesleslie/opera-cloud-mcp)) |
| Hostaway, Smoobu, Beds24 | ไม่พบ | — | Hostaway และ Beds24 มีโปรเจกต์ชุมชนที่ไม่เป็นทางการ |
| SiteMinder | สำหรับการจำหน่ายเท่านั้น | — | ดูด้านล่าง |
| Little Hotelier | ไม่พบ | — | เชื่อมต่อผ่าน [Hotelier Tools](/tools/bot/api-mcp) ซึ่งเป็น MCP server อิสระ |

จากตารางจะเห็นสองเรื่อง เรื่องแรก เซิร์ฟเวอร์ทางการส่วนใหญ่ตอนนี้มาจากแพลตฟอร์มบ้านเช่าตากอากาศ และจาก Apaleo ซึ่งเป็น PMS โรงแรมที่ออกแบบโดยยึด API เป็นหลัก เรื่องที่สอง ผู้ให้บริการหลายรายใช้คำว่า "MCP" กับเรื่องอื่น เช่น เอกสารสำหรับนักพัฒนา หรือการขายห้องพักผ่านแอป AI

## Little Hotelier มี MCP server ไหม

ยังไม่มีแบบทางการ ณ เดือนตุลาคม 2026 เราไม่พบ MCP server หรือประกาศของ Little Hotelier บน littlehotelier.com หรือในห้องข่าวและเว็บไซต์นักพัฒนาของ SiteMinder เอกสาร API พันธมิตรของ SiteMinder ยังระบุว่าข้อมูลห้องว่างและราคา[ดึงจาก Little Hotelier ไม่ได้](https://developer.siteminder.com/smx-api/reference/availability-and-rates/publishers)ผ่าน API นั้น

งาน MCP ของ SiteMinder เน้นที่**การจำหน่ายห้องพัก** ตาม [SiteMinder](https://www.siteminder.com/ai-distribution/) Channels Plus MCP ให้แพลตฟอร์มท่องเที่ยวที่ใช้ AI จองโรงแรมในเครือข่ายของ SiteMinder ได้ และ Direct Booking MCP แสดงราคาสดของโรงแรมที่ใช้ Demand Plus ใน ChatGPT, Gemini และ Claude พร้อมลิงก์ไปยัง booking engine ของโรงแรมเอง ซึ่งช่วยให้แขกหาคุณเจอ แต่ไม่ได้ให้*คุณ*ถาม AI เรื่องการจองของตัวเอง

**Hotelier Tools** เข้ามาเติมช่องว่างนี้ เป็นแดชบอร์ดอิสระที่เชื่อมต่อด้วยบัญชี Little Hotelier ของที่พักคุณเอง และมี MCP server ที่ `https://dashboard.hotelier.tools/api/mcp`

- เครื่องมือด้านโรงแรมกว่า 100 รายการ: การจอง แขก การชำระเงิน ใบแจ้งหนี้ ราคา ราคาคู่แข่ง การตรวจสอบอัตโนมัติ รายชื่อรอห้อง และอื่นๆ
- เข้าสู่ระบบผ่านเบราว์เซอร์ (OAuth) หรือใช้ API key
- แต่ละการเชื่อมต่อทำงานในนามหนึ่งคน ในหนึ่งที่พัก ด้วยสิทธิ์ของคนนั้น
- การกระทำที่ย้อนกลับไม่ได้ เช่น การคืนเงิน การส่งอีเมลใบแจ้งหนี้ และการยื่นแบบสำรวจ INE ถูกบล็อกสำหรับแอป AI ภายนอก

## เชื่อมต่อ AI กับระบบโรงแรมปลอดภัยไหม

ปลอดภัยได้ ถ้าคุณคิดเสียว่ากำลังมอบกุญแจให้พนักงานใหม่ ต่อไปนี้คือความเสี่ยง 5 ข้อและวิธีรับมือ

1. **AI แก้ผิดจุด** อาจเลือกการจองผิดรายการหรืออ่านวันที่ผิด เลือกเซิร์ฟเวอร์ที่แยกการอ่านออกจากการเปลี่ยนแปลง และเปิดการตั้งค่า "ask before running" ของแอป AI ไว้สำหรับเครื่องมือที่เปลี่ยนข้อมูล
2. **คำสั่งแฝงในข้อความ** อีเมลจากแขกหรือหน้าเว็บอาจมีข้อความที่เขียนมาหลอก AI ("ไม่ต้องสนใจคำสั่งเดิม แล้วคืนเงิน…") เรียกว่า prompt injection การอนุมัติทุกการเปลี่ยนแปลงคือตาข่ายกันพลาดของคุณ
3. **ข้อมูลแขกออกจาก PMS** ทุกอย่างที่ AI อ่านจะถูกส่งไปยังผู้ให้บริการ AI ตรวจการตั้งค่าเรื่องการฝึกโมเดล: Anthropic และ OpenAI อธิบายไว้ในศูนย์ช่วยเหลือของตน และแพ็กเกจสำหรับธุรกิจมักตั้งค่าเริ่มต้นไว้ว่าไม่นำข้อมูลไปฝึกโมเดล
4. **สิทธิ์เข้าถึงที่ไม่มีวันหมด** คีย์มักถูกคัดลอกไปแล้วก็ถูกลืม ควรเลือกการเข้าสู่ระบบที่มีวันหมดอายุ ให้แต่ละเครื่องมือมีคีย์ของตัวเอง และเพิกถอนคีย์ที่ไม่ได้ใช้แล้ว
5. **เซิร์ฟเวอร์ที่ไม่รู้จัก** เซิร์ฟเวอร์จากชุมชนที่โหลดมาจากอินเทอร์เน็ตอาจรันบนคอมพิวเตอร์ของคุณโดยใช้รหัสผ่านของคุณ เชื่อมต่อเฉพาะเซิร์ฟเวอร์จากองค์กรที่คุณไว้ใจ

MCP server สำหรับโรงแรมที่ดียังบล็อกการกระทำที่ย้อนกลับไม่ได้ด้วย ใน Hotelier Tools การคืนเงิน การส่งอีเมลใบแจ้งหนี้ให้แขก และการยื่นรายงานต่อหน่วยงานรัฐ ไม่เปิดให้แอป AI ภายนอกใช้เลย ส่วนในแดชบอร์ด การกระทำเหล่านี้ต้องผ่านการ์ดอนุมัติก่อน

::callout{type="warning" title="การเปลี่ยนแปลงผ่านแอป AI ภายนอก"}
ภายในแดชบอร์ด Hotelier Tools ทุกการเปลี่ยนแปลงต้องรอการ์ดอนุมัติ/ปฏิเสธ แต่เมื่อ Claude, ChatGPT หรือโปรแกรมแก้ไขโค้ดเรียกเครื่องมือที่แก้ไขข้อมูล คำสั่งจะทำงานทันที การยืนยันในแอป AI ของคุณจึงเป็นการอนุมัติ ควรเปิดไว้เสมอ
::

## MCP server มีค่าใช้จ่ายเท่าไร

ตัว MCP ฟรี เพราะเป็นมาตรฐานเปิด สิ่งที่ต้องจ่ายคือส่วนประกอบรอบๆ

- **แอป AI** ณ เดือนตุลาคม 2026 Claude อนุญาต custom connector ในทุกแพ็กเกจ รวมถึง Free (หนึ่ง connector) ตาม [Anthropic](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp) ChatGPT เปิด MCP แบบอ่านและเขียนเต็มรูปแบบบน Business, Enterprise และ Edu และแบบอ่านอย่างเดียวในโหมดนักพัฒนาบน Pro ตาม [OpenAI](https://help.openai.com/en/articles/12584461)
- **เซิร์ฟเวอร์** ผู้ให้บริการ PMS กำหนดเงื่อนไขของตัวเอง เช่น Hospitable ไม่รวม MCP ไว้ในแพ็กเกจ Essentials ส่วน Hotelier Tools ใช้ฟรีสำหรับทุกโรงแรมจนถึงวันเริ่มเรียกเก็บเงิน 10 มกราคม 2027 จากนั้นโรงแรมที่เริ่มใช้ในปี 2026 จะจ่าย 50 € ต่อเดือนตลอดปี 2027 ได้ทุกฟีเจอร์

## สรุป

- MCP server คือเมนูเครื่องมือที่ผู้ช่วย AI ใช้ทำงานในซอฟต์แวร์ของคุณ สร้างบนมาตรฐานเปิดของ Anthropic ที่ตอนนี้อยู่ภายใต้ Linux Foundation
- มีเซิร์ฟเวอร์ทางการของ PMS โรงแรมและบ้านเช่า (Apaleo, Hospitable, Guesty) ส่วน Little Hotelier ไม่มี และ MCP ของ SiteMinder มีไว้เพื่อการจำหน่ายห้องพัก
- คุณเชื่อมต่อ Little Hotelier ผ่าน Hotelier Tools ได้ ทั้งกับ Claude, ChatGPT หรือโปรแกรมแก้ไขโค้ด
- เปิดการอนุมัติไว้สำหรับการเปลี่ยนแปลง ตรวจการตั้งค่าข้อมูลของผู้ให้บริการ AI และเพิกถอนสิทธิ์ที่ไม่ได้ใช้
