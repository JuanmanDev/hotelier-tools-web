Hotelier Tools is an independent project by **Juan Manuel Béc.**, a software developer based in Spain. It adds to Little Hotelier what a small hotel's front desk often has to do by hand. It is run by an individual, not a company.

## What Hotelier Tools is

- **A dashboard** at [dashboard.hotelier.tools](https://dashboard.hotelier.tools) that sits next to Little Hotelier: bulk invoices and invoices at checkout, automated reservation checks, dynamic pricing, a guest inbox for WhatsApp, email and Booking.com, an AI assistant, a waitlist for sold-out dates and Spain's INE occupancy survey. It also offers a REST API and an MCP server, so tools such as Claude or ChatGPT can work with your hotel's data. See [all dashboard features](/tools/bot), or try the [public demo](https://demo.hotelier.tools) with an invented hotel.
- **Free browser scripts** for Tampermonkey that improve Little Hotelier's own screens: wider tables, compact calendars, commissions and prices where you need them, and other small fixes. See [all scripts](/tools/ui).
- **Guides** about running a property on Little Hotelier, in [the blog](/blog).

## How it works with Little Hotelier

Your reservations, rates and calendar stay in Little Hotelier. The scripts run inside your own Little Hotelier session and send nothing to Hotelier Tools. The dashboard connects with your property's own Little Hotelier login, stored encrypted (AES-256-GCM), so it can only do what that login can do, and every change it makes is visible in Little Hotelier as usual.

## Independent from SiteMinder

Hotelier Tools is **not affiliated with or endorsed by SiteMinder or Little Hotelier**. It is not an official integration or partner product. Little Hotelier and SiteMinder are named only to describe what Hotelier Tools works with.

## Public source code

The scripts are free, and their source code is public on GitHub in the [TampermonkeyLittleHotelier repository](https://github.com/JuanmanDev/TampermonkeyLittleHotelier). Anyone can read what a script does before installing it, report a problem or suggest a change. The source code of this website is also public, in the [hotelier-tools-web repository](https://github.com/JuanmanDev/hotelier-tools-web).

## Pricing
