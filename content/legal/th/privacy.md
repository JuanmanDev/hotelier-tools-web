## สถิติการเข้าชม

เรานับจำนวนการเข้าชมด้วย Umami ซึ่งเป็นเครื่องมือวิเคราะห์แบบโอเพนซอร์สที่เราโฮสต์เองที่ umami.hotelier.tools เราไม่ใช้ Google Analytics แท็กโฆษณา หรือตัวติดตามของโซเชียลมีเดียบนเว็บไซต์นี้

เมื่อคุณเปิดหน้าเว็บ เบราว์เซอร์ของคุณจะส่งข้อมูลต่อไปนี้ไปยังเซิร์ฟเวอร์สถิติ:

- ที่อยู่และชื่อของหน้าเว็บ และเว็บไซต์ที่คุณมาจาก (หากมี)
- ภาษาของเบราว์เซอร์และขนาดหน้าจอของคุณ
- เหตุการณ์ต่าง ๆ เช่น ลิงก์และปุ่มที่คุณคลิก (ข้อความที่มองเห็นและที่อยู่ลิงก์ ตำแหน่งบนหน้าที่คุณคลิก และขนาดหน้าต่าง) และส่วนของหน้าที่คุณเลื่อนมาถึง

ข้อความที่คุณพิมพ์ในแบบฟอร์มจะไม่ถูกส่ง Umami ไม่ตั้งค่าคุกกี้ เช่นเดียวกับเว็บเซิร์ฟเวอร์ทั่วไป เซิร์ฟเวอร์สถิติยังได้รับที่อยู่ IP และรายละเอียดพื้นฐานของเบราว์เซอร์ของคุณในแต่ละคำขอ

เราใช้สถิติเหล่านี้ในรูปแบบรวม เพื่อทราบว่าหน้าและคุณสมบัติใดมีประโยชน์ และเพื่อปรับปรุงเว็บไซต์ เราไม่ใช้สถิติเหล่านี้เพื่อระบุตัวตนของคุณ และเราไม่ขายหรือนำไปใช้เพื่อการโฆษณา

**ฐานทางกฎหมาย:** ประโยชน์โดยชอบด้วยกฎหมายของเราในการทำความเข้าใจว่ามีการใช้เว็บไซต์อย่างไร (มาตรา 6(1)(f) GDPR) โดยใช้เครื่องมือที่ทำงานได้โดยไม่ต้องใช้คุกกี้และอยู่บนเซิร์ฟเวอร์ของเราเอง

**วิธีปฏิเสธ:** บนเว็บไซต์นี้ ให้เปิดคอนโซลนักพัฒนาของเบราว์เซอร์แล้วรัน `localStorage.setItem('umami.disabled', '1')` หลังจากนั้นเบราว์เซอร์นั้นจะไม่ส่งสถิติ ตัวบล็อกเนื้อหาที่บล็อกการวิเคราะห์ก็ใช้ได้เช่นกัน

## แบบฟอร์มติดต่อ

แบบฟอร์มติดต่อไม่ส่งสิ่งใดไปยังเซิร์ฟเวอร์ของเรา เมื่อคุณกด **ส่งข้อความ** แบบฟอร์มจะเปิดแอปอีเมลของคุณเองพร้อมข้อความถึง JuanmaDeveloper+hotelierTools@outlook.com ซึ่งกรอกไว้ตามที่คุณพิมพ์ ได้แก่ ชื่อและอีเมลของคุณ และอาจรวมถึงโทรศัพท์ ชื่อโรงแรม หัวข้อ และข้อความ จะไม่มีสิ่งใดถึงเราจนกว่าคุณจะส่งอีเมลนั้นด้วยตนเอง

เมื่อคุณเขียนถึงเรา เราจะได้รับที่อยู่อีเมลของคุณและทุกสิ่งที่คุณใส่มา เราใช้ข้อมูลนี้เพื่อตอบคุณและติดตามคำขอของคุณเท่านั้น กล่องจดหมายของเราเป็นบัญชี Outlook.com ดังนั้น Microsoft จัดเก็บข้อความเหล่านี้ในฐานะผู้ให้บริการอีเมลของเรา

**ฐานทางกฎหมาย:** ความยินยอมของคุณเมื่อคุณทำเครื่องหมายในช่องและส่งอีเมล (มาตรา 6(1)(a) GDPR) และเมื่อคุณสอบถามเกี่ยวกับการใช้ Hotelier Tools คือขั้นตอนที่คุณร้องขอก่อนเริ่มใช้งาน (มาตรา 6(1)(b) GDPR)

**ระยะเวลาการเก็บรักษา:** เราเก็บข้อความของคุณไว้นานเท่าที่จำเป็นต่อการดำเนินการตามคำขอและการติดตามผลใด ๆ แล้วจึงลบ เว้นแต่กฎหมายกำหนดให้เราต้องเก็บไว้ คุณสามารถขอให้เราลบได้ทุกเมื่อ

## การโฮสต์

เว็บไซต์โฮสต์อยู่บน Vercel เพื่อส่งมอบหน้าเว็บและรักษาความปลอดภัย ผู้ให้บริการโฮสติ้งประมวลผลข้อมูลทางเทคนิค เช่น ที่อยู่ IP รายละเอียดเบราว์เซอร์ หน้าที่ร้องขอ และเวลาของคำขอ

**ฐานทางกฎหมาย:** ประโยชน์โดยชอบด้วยกฎหมายของเราในการดำเนินเว็บไซต์ที่ปลอดภัยและใช้งานได้ (มาตรา 6(1)(f) GDPR) ผู้ให้บริการของเราอาจประมวลผลข้อมูลนอกเขตเศรษฐกิจยุโรป ในกรณีดังกล่าว ต้องอาศัยมาตรการป้องกันที่ GDPR กำหนดสำหรับการโอนข้อมูลระหว่างประเทศ

## คุกกี้และพื้นที่จัดเก็บของเบราว์เซอร์

เราไม่ใช้คุกกี้โฆษณาหรือคุกกี้ติดตาม เว็บไซต์เก็บรายการเล็ก ๆ ไม่กี่รายการไว้ในเบราว์เซอร์ของคุณเพื่อให้ทำงานตามที่คุณเลือก:

| ชื่อ | ประเภท | หน้าที่ | ระยะเวลา |
| --- | --- | --- | --- |
| `i18n_redirected` | คุกกี้ | จดจำภาษาของคุณ เพื่อให้หน้าแรกเปิดในภาษานั้น | 1 ปี |
| `nuxt-color-mode` | พื้นที่จัดเก็บในเครื่อง | จดจำโหมดสว่างหรือมืด | จนกว่าคุณจะล้าง |
| `umami.disabled` | พื้นที่จัดเก็บในเครื่อง | เฉพาะเมื่อคุณตั้งค่าเอง: หยุดสถิติการเข้าชม | จนกว่าคุณจะล้าง |

รายการเหล่านี้ใช้เพื่อคุณสมบัติที่คุณใช้เท่านั้น จึงไม่ต้องได้รับความยินยอมจากคุณ คุณสามารถลบได้ทุกเมื่อในการตั้งค่าเบราว์เซอร์

ฟอนต์และรูปภาพให้บริการจากเว็บไซต์นี้ ลิงก์ไปยังเว็บไซต์อื่น เช่น GitHub แดชบอร์ด หรือ Little Hotelier จะพาคุณไปยังบริการที่มีนโยบายความเป็นส่วนตัวของตนเอง

## สคริปต์เบราว์เซอร์ฟรี

สคริปต์ Tampermonkey ทำงานในเบราว์เซอร์ของคุณ ภายในเซสชัน Little Hotelier ของคุณเอง สคริปต์สื่อสารกับ Little Hotelier เท่านั้น (และกับ Chekin สำหรับสคริปต์เดียวที่สร้างขึ้นสำหรับบริการนั้น) สคริปต์ไม่ส่งสิ่งใดไปยัง Hotelier Tools และเราไม่ได้รับข้อมูลใดจากสคริปต์ เมื่อ Tampermonkey ตรวจสอบการอัปเดต จะดาวน์โหลดสคริปต์จาก GitHub ซึ่งเห็นคำขอนั้นเหมือนการดาวน์โหลดอื่น ๆ

## แดชบอร์ด

แดชบอร์ดเป็นบริการแยกต่างหากที่มีการเข้าสู่ระบบของตนเอง โดยสรุป:

- **บัญชีของคุณ** เราประมวลผลรายละเอียดบัญชีของคุณ เช่น ที่อยู่อีเมลและวิธีที่คุณเข้าสู่ระบบ (เช่น พาสคีย์)
- **การเข้าสู่ระบบที่เชื่อมต่อ** คุณเชื่อมต่อ Little Hotelier ที่ **Credentials** และเลือกเชื่อมต่อ Booking.com extranet กล่องจดหมาย (Google, Microsoft หรือบัญชี IMAP/SMTP ใด ๆ) และ WhatsApp ผ่านเซิร์ฟเวอร์ WAHA ที่คุณจัดหาเองได้ ข้อมูลเข้าสู่ระบบของ Little Hotelier, Booking.com และกล่องจดหมายจัดเก็บแบบเข้ารหัส (AES-256-GCM) โรงแรมในสเปนที่ยื่นแบบสำรวจ INE ยังสามารถบันทึกรหัสผ่าน IRIA ซึ่งจัดเก็บแบบเข้ารหัสและไม่แสดงเป็นข้อความธรรมดา
- **ข้อมูลโรงแรม** ด้วยข้อมูลเข้าสู่ระบบ Little Hotelier ของคุณ แดชบอร์ดอ่านการจอง แขก ราคา ห้องว่าง ใบแจ้งหนี้ และรายละเอียดที่พักที่คุณสมบัติที่คุณใช้ต้องการ และทำการเปลี่ยนแปลงตามที่คุณสั่ง แดชบอร์ดทำได้เฉพาะสิ่งที่ข้อมูลเข้าสู่ระบบนั้นทำได้ ช่องทางที่เชื่อมต่อนำข้อความของแขกเข้ามา ในหน้ารายการรอสาธารณะ แขกฝากรายละเอียดการติดต่อไว้ ซึ่งจะถูกลบออกจากรายการที่ปิดแล้วหลังจาก 90 วัน
- **คุณสมบัติ AI** เมื่อผู้ช่วย AI หรือกล่องข้อความแขกอ่านข้อความหรือรายละเอียดการจอง ผู้ให้บริการ AI จะประมวลผลข้อมูลนั้น หากคุณเชื่อมต่อ Claude, ChatGPT หรือผู้ช่วยอื่นผ่าน API หรือเซิร์ฟเวอร์ MCP ผลลัพธ์ที่ได้รับ (เช่น ชื่อแขก วันที่ และจำนวนเงิน) จะเข้าสู่การสนทนานั้น และผู้ให้บริการรายนั้นจะจัดการภายใต้ข้อกำหนดของแพ็กเกจของคุณ
- **การเข้าถึงที่คุณเพิกถอนได้** คีย์ API และการเชื่อมต่อผู้ช่วยแสดงอยู่ใน **Developer > API Keys** ซึ่งคุณสามารถเพิกถอนได้ทันที การเข้าสู่ระบบของผู้ช่วยหมดอายุหลังจาก 30 วัน

**ใครรับผิดชอบข้อมูลโรงแรม** สำหรับข้อมูลการจอง แขก และข้อความที่แดชบอร์ดประมวลผลให้โรงแรมของคุณ **โรงแรมของคุณเป็นผู้ควบคุมข้อมูล** และ Hotelier Tools ทำหน้าที่เป็น**ผู้ประมวลผลข้อมูล**แทนโรงแรม โดยปฏิบัติตามคำสั่งของโรงแรมและข้อตกลงการประมวลผลข้อมูล แขกที่ต้องการใช้สิทธิของตนควรติดต่อโรงแรม และเราจะช่วยโรงแรมในการตอบ สำหรับข้อมูลบัญชีของแดชบอร์ดเอง Hotelier Tools เป็นผู้ควบคุมข้อมูล

**ระยะเวลาการเก็บรักษา** ข้อมูลแดชบอร์ดจะถูกเก็บไว้ตราบเท่าที่บัญชีของคุณยังใช้งานอยู่และนานเท่าที่จำเป็นต่อการให้บริการ หรือนานกว่านั้นเฉพาะเมื่อกฎหมายกำหนด คุณสามารถลบการเชื่อมต่อได้ทุกเมื่อและขอให้เราลบบัญชีและข้อมูลของคุณ

## ผู้ที่ได้รับข้อมูลส่วนบุคคล

เราไม่ขายข้อมูลส่วนบุคคล เราแบ่งปันเฉพาะกับผู้ให้บริการที่จำเป็นต่อการดำเนินงาน Hotelier Tools (เช่น โฮสติ้งและอีเมล) กับบริการที่คุณเชื่อมต่อเอง หรือเมื่อกฎหมายกำหนดให้เราต้องทำ

## สิทธิของคุณ

คุณสามารถขอให้เรา:

- ให้สำเนาข้อมูลส่วนบุคคลของคุณ (สิทธิในการเข้าถึง)
- แก้ไขข้อมูลให้ถูกต้อง (สิทธิในการแก้ไข)
- ลบข้อมูล (สิทธิในการลบ)
