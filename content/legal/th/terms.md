ข้อกำหนดเหล่านี้มีผลเมื่อคุณใช้เว็บไซต์ Hotelier Tools (hotelier.tools) สคริปต์เบราว์เซอร์ฟรีที่แสดงไว้บนเว็บไซต์ และแดชบอร์ด Hotelier Tools (dashboard.hotelier.tools) การใช้บริการใด ๆ เหล่านี้ถือว่าคุณยอมรับข้อกำหนดนี้ หากคุณไม่เห็นด้วย โปรดอย่าใช้บริการ

Hotelier Tools สร้างขึ้นสำหรับโรงแรมและธุรกิจที่พักอื่น ๆ และสำหรับผู้ที่ทำงานในธุรกิจเหล่านั้น เป็นเครื่องมือระดับมืออาชีพ ไม่ใช่บริการสำหรับผู้บริโภค

## การเชื่อมต่ออิสระที่ไม่เป็นทางการ

Hotelier Tools **ไม่มีความเกี่ยวข้องหรือได้รับการรับรองจาก SiteMinder หรือ Little Hotelier** Little Hotelier และ SiteMinder เป็นเครื่องหมายการค้าของเจ้าของ และถูกกล่าวถึงที่นี่เพื่ออธิบายบริการที่ Hotelier Tools ใช้งานร่วมด้วยเท่านั้น เช่นเดียวกับ Booking.com, WhatsApp, Claude, ChatGPT และบริการอื่นที่กล่าวถึงบนเว็บไซต์

สคริปต์ทำงานภายในเซสชัน Little Hotelier ของคุณเอง และแดชบอร์ดเชื่อมต่อด้วยข้อมูลเข้าสู่ระบบ Little Hotelier ของที่พักคุณเอง โดยใช้เว็บเอนด์พอยต์เดียวกับเว็บแอป Little Hotelier นี่ไม่ใช่ API ของพันธมิตรอย่างเป็นทางการ ดังนั้น:

- **คุณมีหน้าที่รับผิดชอบ** ในการตรวจสอบให้แน่ใจว่าการใช้ Hotelier Tools ของคุณได้รับอนุญาตภายใต้ข้อตกลงของคุณเองกับ SiteMinder หรือ Little Hotelier และกับบริการอื่นที่คุณเชื่อมต่อ เช่น Booking.com หรือ WhatsApp
- Little Hotelier หรือบริการอื่นที่เชื่อมต่ออาจเปลี่ยนวิธีการทำงานเมื่อใดก็ได้ สคริปต์หรือคุณสมบัติของแดชบอร์ดอาจหยุดทำงานจนกว่าจะได้รับการอัปเดต และบางคุณสมบัติอาจไม่สามารถใช้งานได้อีกต่อไป
- Hotelier Tools ทำได้เฉพาะสิ่งที่ข้อมูลเข้าสู่ระบบของคุณทำได้ ทุกการเปลี่ยนแปลงที่ทำจะมองเห็นได้ใน Little Hotelier ตามปกติ

## สคริปต์เบราว์เซอร์ฟรี

สคริปต์ Tampermonkey ใช้งานได้ฟรี ซอร์สโค้ดเปิดเผยต่อสาธารณะใน[ที่เก็บ TampermonkeyLittleHotelier บน GitHub](https://github.com/JuanmanDev/TampermonkeyLittleHotelier) และสัญญาอนุญาตใด ๆ ที่เผยแพร่ในที่เก็บนั้นกำหนดวิธีที่คุณใช้และแก้ไขโค้ดได้

คุณติดตั้งและรันสคริปต์ด้วยตนเองในเบราว์เซอร์ของคุณเอง อ่านโค้ดหรือปิดสคริปต์ได้ทุกเมื่อใน Tampermonkey ติดตั้งเฉพาะสคริปต์ที่คุณต้องการ และตรวจสอบว่าสคริปต์ทำงานตามที่คุณคาดหวังในที่พักของคุณ

## แดชบอร์ด

- **บัญชีของคุณ** เก็บข้อมูลเข้าสู่ระบบของคุณให้ปลอดภัยและอย่าแบ่งปันกับผู้อื่น คุณรับผิดชอบต่อสิ่งที่เกิดขึ้นในบัญชีของคุณ รวมถึงการดำเนินการผ่านคีย์ API และผู้ช่วย AI ที่คุณเชื่อมต่อ เพิกถอนคีย์และการเชื่อมต่อที่คุณไม่ได้ใช้แล้ว
- **ข้อมูลของคุณและแขกของคุณ** คุณต้องมีสิทธิในการเชื่อมต่อข้อมูลเข้าสู่ระบบและประมวลผลข้อมูลที่คุณนำเข้าสู่แดชบอร์ด สำหรับข้อมูลแขกและการจอง โรงแรมของคุณเป็นผู้ควบคุมข้อมูล และ Hotelier Tools ประมวลผลแทนคุณ ตามที่อธิบายไว้ใน[นโยบายความเป็นส่วนตัว](/privacy)และข้อตกลงการประมวลผลข้อมูลของแดชบอร์ด
- **ตรวจสอบสิ่งสำคัญ** รายงาน ใบแจ้งหนี้ คำแนะนำด้านราคา การตรวจสอบอัตโนมัติ และคำตอบที่เขียนโดย AI ช่วยให้คุณทำงานได้เร็วขึ้น แต่คุณยังคงรับผิดชอบต่อการตัดสินใจของคุณและต่อสิ่งที่คุณส่งให้แขก หน่วยงานภาษี และผู้อื่น โปรดตรวจทานผลลัพธ์สำคัญก่อนนำไปใช้
- **AI และผู้ช่วยที่เชื่อมต่อ** ในแดชบอร์ด การเปลี่ยนแปลงที่ผู้ช่วย AI เสนอต้องได้รับการอนุมัติจากคุณ เมื่อคุณเชื่อมต่อผู้ช่วยภายนอก เช่น Claude หรือ ChatGPT ผ่าน API หรือเซิร์ฟเวอร์ MCP การดำเนินการเขียนของผู้ช่วยนั้นจะทำงานทันที คุณเป็นผู้ตัดสินใจว่าจะอนุญาตให้ทำอะไร
- **การใช้งานที่เหมาะสม** ห้ามใช้ Hotelier Tools เพื่อสิ่งที่ผิดกฎหมาย เพื่อส่งสแปม เพื่อเข้าถึงข้อมูลที่คุณไม่มีสิทธิ หรือในลักษณะที่เป็นอันตรายต่อบริการหรือผู้ใช้อื่น เราอาจระงับการเข้าถึงที่ทำให้บริการ ผู้ใช้อื่น หรือบัญชีที่เชื่อมต่อตกอยู่ในความเสี่ยง
- **เดโมสาธารณะ** ที่ demo.hotelier.tools ใช้โรงแรมสมมติ ห้ามพิมพ์ข้อมูลเข้าสู่ระบบหรือข้อมูลส่วนบุคคลจริงที่นั่นโดยเด็ดขาด

## คุณสมบัติเบต้าและอัลฟ่า

หลายคุณสมบัติมีเครื่องหมาย **เบต้า** หรือ **อัลฟ่า** คุณสมบัติเบต้าทำงานได้ดีและยังอยู่ระหว่างการขัดเกลา คุณสมบัติอัลฟ่าเป็นเวอร์ชันเริ่มต้นที่เปลี่ยนแปลงบ่อย คุณสมบัติในสถานะใดสถานะหนึ่งอาจเปลี่ยนแปลง ถูกจำกัด หรือถอนออกโดยไม่แจ้งล่วงหน้า และคุณใช้งานโดยทราบเรื่องนี้

## ราคา

สคริปต์เบราว์เซอร์ใช้งานได้ฟรีและจะฟรีต่อไป

แดชบอร์ดใช้งานได้ฟรีสำหรับทุกโรงแรม โดยรวมทุกคุณสมบัติ จนถึงวันที่ **10 มกราคม 2027** ซึ่งเป็นวันที่เริ่มเรียกเก็บเงิน โรงแรมที่เริ่มใช้ในปี 2026 จะชำระ **50 ยูโรต่อโรงแรมต่อเดือนตลอดปี 2027** โดยรวมทุกคุณสมบัติ ราคาสำหรับกรณีอื่นและหลังปี 2027 จะประกาศก่อนมีผลบังคับใช้ คุณสมบัติที่ใช้เครดิต AI จะแสดงโควตาและยอดคงเหลือของคุณในแดชบอร์ด

คุณจะได้รับแจ้งก่อนที่จะมีการเรียกเก็บเงินใด ๆ และคุณสามารถหยุดใช้แดชบอร์ดได้ทุกเมื่อ

## ความพร้อมใช้งานและการเปลี่ยนแปลง

Hotelier Tools ให้บริการ **"ตามสภาพ" และ "ตามที่มีอยู่"** เราพยายามให้บริการทำงานต่อเนื่องและถูกต้อง แต่ไม่สามารถรับรองว่าจะพร้อมใช้งานตลอดเวลา ปราศจากข้อผิดพลาด หรือเหมาะกับวัตถุประสงค์เฉพาะ เราอาจเปลี่ยนแปลง ระงับ หรือยุติส่วนใดส่วนหนึ่งของบริการ หากการเปลี่ยนแปลงกระทบผู้ใช้ที่ชำระเงินอย่างมีนัยสำคัญ เราจะแจ้งล่วงหน้าตามสมควร

## ความรับผิด

ในขอบเขตที่กฎหมายอนุญาต:

- เราไม่รับผิดต่อความสูญเสียทางอ้อมหรือความสูญเสียที่เป็นผลสืบเนื่อง เช่น การจองที่สูญเสีย รายได้ที่สูญเสีย หรือกำไรที่สูญเสีย
- เราไม่รับผิดต่อปัญหาที่เกิดจาก Little Hotelier, SiteMinder, Booking.com, ผู้ให้บริการ AI หรือบริการของบุคคลที่สามอื่น ๆ หรือจากการเปลี่ยนแปลงที่บุคคลเหล่านั้นทำ
- สำหรับแดชบอร์ด ความรับผิดรวมของเราจำกัดอยู่ที่จำนวนเงินที่คุณชำระให้เราสำหรับแดชบอร์ดในช่วง 12 เดือนก่อนเหตุการณ์ที่ก่อให้เกิดข้อเรียกร้อง สำหรับสคริปต์ฟรีและช่วงเวลาที่ใช้ฟรี หมายความว่าความรับผิดของเราจำกัดอยู่ที่ขั้นต่ำสุดที่กฎหมายอนุญาต

ไม่มีข้อใดในข้อกำหนดนี้จำกัดความรับผิดสำหรับการกระทำโดยเจตนาหรือความประมาทเลินเล่ออย่างร้ายแรง หรือความรับผิดใด ๆ ที่กฎหมายไม่อนุญาตให้จำกัด

## ทรัพย์สินทางปัญญา

ชื่อ Hotelier Tools ข้อความบนเว็บไซต์ คู่มือ และการออกแบบเป็นของผู้เขียน เว้นแต่ระบุไว้เป็นอย่างอื่น ซอร์สโค้ดที่เผยแพร่บน GitHub อยู่ภายใต้สิ่งที่ที่เก็บนั้นระบุไว้ คุณยังคงถือสิทธิทั้งหมดในข้อมูลของคุณเอง

## การยุติการใช้งาน

คุณสามารถหยุดใช้ Hotelier Tools ได้ทุกเมื่อ: ถอนการติดตั้งสคริปต์ เพิกถอนการเชื่อมต่อ และขอให้เราลบบัญชีแดชบอร์ดของคุณ เราอาจยุติหรือระงับการเข้าถึงหากมีการละเมิดข้อกำหนดนี้อย่างร้ายแรง

## การเปลี่ยนแปลงข้อกำหนดนี้

เราอาจปรับปรุงข้อกำหนดนี้ วันที่ที่ด้านบนของหน้าแสดงเวอร์ชันล่าสุด หากการเปลี่ยนแปลงมีความสำคัญ เราจะแจ้งบนเว็บไซต์หรือในแดชบอร์ดก่อนมีผลบังคับใช้ การใช้ Hotelier Tools ต่อไปหลังจากนั้นหมายความว่าคุณยอมรับข้อกำหนดใหม่

## กฎหมายและข้อพิพาท

ข้อกำหนดนี้อยู่ภายใต้กฎหมายสเปน ข้อพิพาทใด ๆ จะอยู่ในอำนาจของศาลสเปน เว้นแต่กฎหมายบังคับให้สิทธิแก่คุณในการใช้ศาลอื่น ก่อนดำเนินคดีในศาล โปรดเขียนถึงเราเพื่อให้เราลองแก้ไขปัญหาร่วมกัน
