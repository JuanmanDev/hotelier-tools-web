---
title: "REST API และเซิร์ฟเวอร์ MCP สำหรับข้อมูล Little Hotelier"
---

Hotelier Tools มอบ REST API ให้ที่พัก Little Hotelier ของคุณที่ `https://dashboard.hotelier.tools/api/v1` และเซิร์ฟเวอร์ MCP ที่ `https://dashboard.hotelier.tools/api/mcp` สคริปต์ สเปรดชีต Claude ChatGPT Cursor หรือ VS Code ของคุณจึงอ่านการจอง ผู้เข้าพัก ราคา และห้องว่างได้ และทำการเปลี่ยนแปลงบางอย่างได้ ด้วยสิทธิ์เดียวกับบัญชี Hotelier Tools ของคุณ

## วิธีการทำงาน

- **ใช้การล็อกอินของคุณเอง ไม่ใช่ API ของพาร์ทเนอร์** คุณเชื่อมต่อ Little Hotelier ครั้งเดียวที่ **Credentials** และข้อมูลถูกเก็บแบบเข้ารหัส Hotelier Tools ใช้ endpoint เว็บเดียวกับเว็บแอปของ Little Hotelier จึงทำได้เท่าที่การล็อกอินนั้นทำได้ ไม่เกินกว่านั้น
- **REST API** JSON ผ่าน HTTPS: `/reservations` (พร้อมใบแจ้งหนี้และ PDF ต่อการจอง), `/guests`, `/prices`, `/room-types` และ `/methods` สำหรับ method ดิบของ Little Hotelier รายการทั้งหมดอยู่ในสเปก OpenAPI สาธารณะที่ `/api/v1/openapi.json` พร้อมเครื่องมือสำรวจแบบอินเทอร์แอกทีฟและเทมเพลตโค้ดที่ **REST API & Swagger** (`/developer/rest-api`)
- **เซิร์ฟเวอร์ MCP** เซิร์ฟเวอร์ HTTP ระยะไกลที่มีเครื่องมือโรงแรมกว่า 100 รายการ การตั้งค่าสำเร็จรูปสำหรับแต่ละไคลเอนต์อยู่ที่ **MCP Setup** (`/developer/mcp-setup`)

## การยืนยันตัวตนทำงานอย่างไร

- **API keys** สร้างได้ที่ **Developer > API & MCP > API Keys** (`/developer/api-keys`) คีย์ขึ้นต้นด้วย `htk_` แสดงเพียงครั้งเดียว และใส่ในเฮดเดอร์ `Authorization: Bearer` คีย์ไม่มี scope: คีย์ทำงานกับที่พักหนึ่งแห่งในฐานะผู้ที่สร้างคีย์ แต่ละคนมีคีย์ได้สูงสุด 10 คีย์ และเพิกถอนได้ทุกคีย์
- **การเข้าสู่ระบบสำหรับ MCP** ไคลเอนต์ที่รองรับ OAuth เชื่อมต่อได้ด้วยการเข้าสู่ระบบแทน การเข้าสู่ระบบนั้นมีอายุ 30 วัน

## การเรียกอ่านและเขียน

การเรียกอ่านไม่เปลี่ยนอะไรใน Little Hotelier ส่วนการเขียนมีผลจริง: `POST /reservations/{id}/invoices` สร้างใบแจ้งหนี้ใหม่ทุกครั้ง ผ่าน MCP AI เปลี่ยนการจอง (เสนอก่อน แล้วจึงขั้นตอน apply ด้วย `confirmed: true`) บันทึกการชำระเงิน ราคา stop sell รายการรอคิว และงานที่ตั้งเวลาไว้ได้ นอกแดชบอร์ดไม่มีการ์ดอนุมัติ ดังนั้นควรเปิดการอนุมัติเครื่องมือของไคลเอนต์ไว้ การกระทำที่ย้อนกลับไม่ได้ เช่น การคืนเงินหรือการส่งใบแจ้งหนี้ทางอีเมล ถูกบล็อกสำหรับไคลเอนต์ภายนอก

## ข้อจำกัดและข้อควรรู้

- **สถานะ:** REST API และเซิร์ฟเวอร์ MCP อยู่ในขั้น beta การ์ดฝังอยู่ในขั้น alpha
- **ขีดจำกัดอัตราการเรียก:** 100 คำขอต่อนาทีต่อที่อยู่ IP จากนั้นจะได้ `429` พร้อม `Retry-After`
- **การแบ่งหน้า:** สูงสุด 100 การจองต่อการเรียก กรองตามวันเช็คอิน
- **ยังไม่มี:** webhook ขาออก คีย์ sandbox สาธารณะ และแพ็กเกจ SDK
- **ข้อมูลที่ถูกปิดบังยังคงถูกปิดบัง:** Little Hotelier ปิดบังรายละเอียดผู้เข้าพัก 180 วันหลังเช็คเอาต์
- ไม่ใช่ API ทางการของ SiteMinder
